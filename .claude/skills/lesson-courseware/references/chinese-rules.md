# 语文课件规则 (chinese-rules)

Step 0 判定为语文后,先读本文件再创作。语文按**课文序号**组织(第N课),低年级侧重识字写字,中高年级侧重阅读与表达。

## 1. 识字写字页

- 生字教学用 `tianzige` 图元:`{"kind":"tianzige","chars":["印","规"],"pinyin":["yìn","guī"]}`(一次≤6字);拼音以素材包 anchor_text 中"会认字/会写字(带拼音)"为准,**不得自行注音**——素材没给拼音就只列字不注音。
- 生字归类呈现:会认字 / 会写字分列;易错笔画直接引用 knowledge_points.learning_objectives 中的表述(如『径』右边是『圣』不要多撇)。
- 多音字/形近字用 `pinyin_line` 或对比表格(`table`)。

## 2. 朗读与感悟

- 导入(warmup)可用课文首句设境;精读段引用限于**教学所需片段**(1~3句),整段抄录违反版权护栏。
- 朗读指导写进 notes:重音、停顿、语气,给示范指令("注意'轻轻地'要读得又轻又慢")。
- 好词佳句积累用 concept 页呈现,callout 提炼修辞/结构特点(如比喻句式)。

## 3. 阅读理解

- 问题链设计:整体感知 → 词语理解 → 句段品读 → 迁移表达,3~4 个主问题放进 concept/例题式页面(problem=主问题,solution_steps=阅读支架,answer=参考表述)。
- 课后练习引用 lessons.official_examples 中"课后练习"条目,不超纲到未学单元的语文要素。

## 4. 课堂练习(practice)

- 中低年级:看拼音写词语、多音字选择、近反义词、按课文内容填空。
- 每题 source 指向对应知识点;开放题(说一说/写一写)answer 写"略",并在答案页给评价要点。

## 5. 板书(board)

课文脉络式:课题居中,主线词/结构图分行呈现(如"秋天的雨 → 是一把钥匙 / 藏着气味 / 吹起喇叭")。

## 6. 特殊纪律

- 素材包 anchor_text 标注了 2024 版篇目变化(如《赠刘景文》已删),**绝不出现在课件中**。
- 古诗教学:诗句原文可整首呈现(短篇幅),配朗读节奏划分手动标注。
